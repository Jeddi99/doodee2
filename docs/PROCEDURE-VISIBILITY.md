## สรุป

- 🟢 ชัดเจน **50/72**
- 🟡 อ่อน **3/72**
- 🔴 มองไม่เห็น **19/72** — ผู้ใช้กดแล้วภาพแทบไม่ต่าง
- ไม่มีบรรทัดตัวเลขเลย **32/72** — เพราะ `evidence` ผูกกับ warp slider เท่านั้น
  หัตถการที่ทำงานบนพื้นผิวล้วน (เลเซอร์ · สกินบูสเตอร์ · รักษาสิว) จึงได้ภาพที่ไม่มีคำอธิบายกำกับ

## ทำไมถึงเป็นแบบนี้

ไม่ใช่บั๊กของการต่อสาย — ทุกแถวเรนเดอร์ผ่านหมด ไม่มี error เหลือ สิ่งที่วัดได้คือ
**ความแรงที่เขียนไว้ใน pipeline ของแคตตาล็อกเอง** เช่น

```
4.1 ฟิลเลอร์ร่องแก้ม   FLATTEN_OP nasolabial strength=0.35   → 0.1% ของภาพ
1.1 ไฮฟู               WARP hifuLifting 59 + jawDefinition 34 → 2.8% ของภาพ
```

`FLATTEN_OP` ลบร่องออกจากผิวที่มีร่องอยู่แล้ว ถ้าใบหน้าที่ทดสอบไม่มีร่องแก้มลึก ผลก็เกือบศูนย์
— ซึ่ง **ถูกต้องทางคลินิก** แต่บนหน้าจอมันแยกไม่ออกจาก "ระบบพัง"

## ทางที่เลือก: บอกความจริงบนจอ ไม่แตะความแรง

ตัดสินใจแล้ว — **ไม่เพิ่มความแรงของ pipeline** เพราะนั่นคือการอ้างผลลัพธ์แรงกว่าที่แหล่งอ้างอิงรองรับ
และ **ไม่ซ่อนแถวที่มองไม่เห็น** เพราะฟิลเลอร์ใต้ตาหรือทำตาสองชั้นไม่ใช่หัตถการที่ควรหายไปจากรายการ

แทนที่จะทำสองอย่างนั้น engine **วัด** ว่าแต่ละมุมเปลี่ยนไปกี่เปอร์เซ็นต์ของพื้นที่ภาพ
แล้วส่งตัวเลขนั้นขึ้นหน้าจอ:

| สถานะ | หน้าจอพูดว่า |
|---|---|
| มุมนี้แทบไม่เปลี่ยน แต่มุมอื่นเปลี่ยน | "มุมนี้แทบไม่ต่างเลย — หัตถการนี้เห็นได้ที่มุมด้านขวา ลองสลับไปดู" |
| ทุกมุมต่ำกว่าเกณฑ์ | "ภาพนี้ต่างจากเดิม 0.115% ของพื้นที่ภาพ ซึ่งน้อยจนแทบมองไม่ออก — **ไม่ใช่ข้อผิดพลาด** แต่แปลว่าบนใบหน้าของคุณ หัตถการนี้ทำให้เปลี่ยนไปน้อยมาก" + ปุ่ม "ลองระดับแรงสุด" ถ้ายังไม่สุด |
| ไม่มีบรรทัดตัวเลข | "หัตถการนี้ทำงานกับพื้นผิวและสีผิว ยังไม่มีงานวิจัยที่ระบุปริมาณหรือระยะเป็นมิลลิเมตรไว้" |
| แถวเก่าที่ยังไม่เคยวัด | เงียบ — ไม่มีตัวเลข ไม่ใช่ศูนย์ |

**ทำไมถึงโชว์ตัวเลขด้วย ไม่ใช่แค่คำตัดสิน** — เพราะตัวเลขคือหลักฐานของประโยคนั้น
และคนที่เทียบสองหัตถการจะเห็นว่า 0.1% กับ 3% ไม่ใช่ "ไม่มีอะไร" แบบเดียวกัน

เกณฑ์อยู่ที่เดียว: `FAINT_FRACTION` ใน `canonical_pipeline.py` · ฝั่ง JS มี `FAINT_PERCENT`
และมีเทสต์อ่านไฟล์ Python มาเทียบ ถ้าสองค่าเลื่อนออกจากกันเมื่อไหร่เทสต์แดงทันที

### ที่ยังไม่ได้ทำ

`meas=0` **32 แถว** ยังไม่มีบรรทัดตัวเลข — หน้าจอบอกเหตุผลแล้ว แต่ถ้าอยากให้มีตัวเลขจริง
ต้องเพิ่ม entry ใน `evidence.EVIDENCE` สำหรับ `FLATTEN_OP`/`TONE_OP` พร้อมแหล่งอ้างอิง
เป็นงานหาข้อมูลทางคลินิก ไม่ใช่งานโค้ด
